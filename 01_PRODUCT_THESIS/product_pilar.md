## **PP01. Chat-integrated Flow**

#### **정의** 

- 파일 관련 작업을 탐색과 대화 두 방식으로 진행하는 흐름  
- 탐색과 대화가 서로 분리되지 않고 하나의 작업 맥락을 공유하도록 하는 원칙

#### **목적**

- 익숙한 폴더 탐색과 검색 방식을 유지하면서도 필요할 때 대화로 전환 가능하게 하기  
- 파일 찾기, 살펴보기, 정리, 활용 과정을 하나의 연속된 경험으로 엮기  
- 새로운 기능과 인터랙션이 이 흐름 안에 자연스럽게 들어올 수 있는 상위 틀 제공

#### **설계 원칙**

- 탐색으로 시작한 작업을 언제든 대화로 이어갈 수 있도록 설계  
- 대화로 시작한 작업을 다시 탐색과 브라우징으로 이어갈 수 있도록 설계  
- 현재 화면, 선택, 필터 상태를 대화의 기본 맥락으로 설정  
- 대화에서 나온 결과와 사용자의 후속 행동이 서로 영향을 주고받도록 연결  
- 새로운 기능을 정의할 때 이 흐름 안에서 어느 지점에 놓이는지 설명 가능하도록 유지

## **PP02. Logical Collections**

#### **정의**

- 물리적 경로와 무관하게 의미와 작업 단위에 따라 파일과 자료를 묶는 콜렉션  
- 동일한 파일이 여러 작업 맥락에서 재사용될 수 있도록 하는 묶음 단위

#### **목적**

- 특정 작업이나 결정을 위해 모은 자료를 이후에도 쉽게 다시 꺼내 쓰기  
- 디렉터리 구조로 표현하기 어려운 관계와 맥락을 드러내기  
- 개별 파일이 아니라 자료 묶음 단위로 생각하고 설계할 수 있는 기반 제공

#### **설계 원칙**

- 해당 콜렉션이 어떤 조건 기준으로 구성되었는지 직관적으로 확인할 수 있게 설계  
- 하나의 엔트리가 여러 콜렉션에 속할 수 있음을 전제로 설계  
- 콜렉션 안에서 어떤 작업이 이루어졌는지 이력과 상태를 함께 쌓이도록 설계  
- 새로운 기능이 특정 콜렉션을 기준으로 동작할 수 있는지 항상 점검  
- 콜렉션을 다른 플로우와 액션의 자연스러운 입력 단위로 사용할 수 있도록 유지

## **PP03. Reusable Actions**

#### **정의**

- 파일과 콜렉션을 다루는 공통된 처리 방식을 이름 붙인 동작 단위  
- 비슷한 작업을 여러 번 할 때 기준과 절차를 다시 만들지 않고 그대로 불러 쓸 수 있는 방법

#### **목적**

- 사람과 시점에 따라 제각각인 관리 방식을 줄이고 일정한 기준 유지하기  
- 같은 유형의 작업을 할 때마다 처음부터 고민하지 않고 준비된 방식을 선택해 사용하기  
- 작은 자동화에서 복잡한 흐름까지 점진적으로 쌓아 올릴 수 있는 기반 제공하기

#### **설계 원칙**

- 액션은 특정 화면이나 도구에 묶이지 않고, 다양한 작업 흐름에서 반복해 사용할 수 있도록 설계  
- 액션이 어떤 입력과 어떤 전제가 있는지 간결하게 표현 가능하도록 설계  
- 여러 액션이 서로 조합되거나 더 큰 흐름의 일부가 될 수 있도록 느슨하게 설계  
- 새로운 기능을 만들 때 기존 액션의 조합이나 변형으로 표현 가능한지 먼저 검토  
- 액션 실행 결과를 나중에 참고할 수 있도록 최소한의 이력과 맥락을 함께 남기도록 설계

## **PP04. Controllable Execution**

#### **정의**

- 자동화와 AI 기반 처리가 항상 사용자의 통제 아래에서 이루어지도록 하는 실행 방식  
- 결과만 전달하는 것이 아니라 과정과 선택지를 함께 제공하는 실행 원칙

#### **목적**

- 파일과 자료에 대한 변경이 예측 가능하고 이해 가능한 형태로 이루어지게 하기  
- 잘못된 실행이나 과도한 변경이 발생했을 때 부담 없이 수정·취소할 수 있게 하기  
- 자동화 수준이 높아져도 사용자가 주도권을 잃지 않도록 하기

#### **설계 원칙**

- 실행 전 어떤 일이 일어날지, 실행 후 어떤 상태가 되었는지 각각 명확히 드러나도록 설계  
- 전부 적용만이 아니라 일부 적용과 재검토를 선택할 수 있도록 설계  
- 실행 결과를 단순 성공/실패가 아니라 다음 판단을 위한 정보로 표현  
- 되돌리기와 이력 조회를 전제로 액션과 흐름을 설계  
- 새로운 AI 기능은 사용자의 통제 가능성을 해치지 않는 범위 안에서 추가
