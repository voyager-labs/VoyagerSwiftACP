## **CF01. Browse Pages**

#### **목표**

- 하나의 탭 안에서 페이지를 브라우저처럼 탐색하고 전환할 수 있게 한다.  
- 탐색 과정 중 각 페이지의 히스토리와 뷰 상태를 예측 가능하도록 보존한다.

#### **시작 조건**

- 현재 탭 내에서 페이지 전환이나 탐색을 시작했을 때  
  - 현재 디렉토리에서 다른 디렉토리로 경로를 이동  
  - 디렉토리 내에서 필터를 적용하여 콜렉션을 생성하는 경우  
  - 저장된 콜렉션을 여는 경우  
  - 채팅 페이지를 여는 경우  
  - 채팅에서 다루는 작업 맥락을 페이지로 여는 경우

#### **핵심 동작**

- 탐색 내역 기반 히스토리 이동  
  - 뒤로/앞으로 이동을 통해 이전/다음 페이지로 돌아가기  
- 계층 구조 기반 탐색  
  - 상위 디렉토리로 이동  
  - 경로 직접 입력하거나 선택하여 디렉토리 열기 등  
- 페이지 타입 간 자연스러운 전환

#### **성공 상태**

- 동일 탭 내에서 페이지 탐색 히스토리가 유지되는 상태  
- 페이지 탐색∙전환 후 이전 페이지로 복귀 시, 선택 요소, 마지막 스크롤 위치 등 상태가 그대로 복원되는 상태

## **CF02. Handle Entries**

#### **목표**

- 엔트리 목록에서 선택한 엔트리에 대해, 파일 관리자의 기본 동작을 일관되고 예측 가능하게 수행할 수 있게 한다.  
- 단일·다중·대량 작업 모두에서, 동작의 안전성과 흐름의 연속성을 보장한다.

#### **시작 조건**

- 하나 이상의 엔트리가 선택된 상태에서 사용자가 명시적으로 열기, 이동, 삭제, 이름 변경 등 엔트리 관련 동작을 요청했을 때

#### **핵심 동작**

- 기본 비파괴 동작 처리  
  - 열기/미리보기/복사 등 엔트리의 내용을 변경하지 않는 기본 동작  
- 가벼운 수정 동작 처리  
  - 이름, 태그, 속성 등 엔트리 수준 메타데이터 수정  
- 구조 변경 및 대량 작업 처리  
  - 이동, 복제, 삭제 등 엔트리 집합 영향 동작 수행  
- 사용자 직접 조작이 아니거나, 충돌, 불확실한 상태의 작업인 경우 검토/승인 절차 제공

#### **성공 상태**

- 선택된 엔트리에 대해 요청된 동작이, 정의된 규칙에 따라 일관되게 반영된 상태  
- 대량·위험 작업을 포함한 모든 처리 결과에 대해, 변경 전후 상태를 추적할 수 있는 정보가 남고, 변경 전 상태로 복구가 가능한 상태  
- 엔트리 처리 수행 과정이 페이지 탐색이나 다른 작업 흐름을 방해하지 않는 상태

## **CF03. Define Logical Collections**

#### **목표**

- 물리적 경로와 무관하게, 조건/의미/작업 단위로 엔트리를 묶는 Logical Collection을 정의하고 탐색 가능하게 한다.

#### **시작 조건**

- 디렉토리 페이지에서 필터를 편집하거나 적용하려는 경우  
- 저장된 콜렉션을 생성/수정/복제/이름 변경하려는 경우  
- 채팅에서 검색 의도 처리 결과로 조건 초안이 만들어져, 이를 콜렉션으로 정리하려는 경우

#### **핵심 동작**

- 조건 정의/편집  
  - 엔트리 속성 기반 조건, 텍스트 쿼리, 제외 조건, 정렬/그룹 기준 등을 조합  
- 결과 적용 및 검증  
  - 조건 적용 시 결과 목록을 갱신하고, 조건 요약이 항상 확인 가능하도록 유지  
- 저장 및 승격  
  - 현재 조건을 이름 등 식별 가능한 콜렉션으로 저장  
  - 저장된 콜렉션은 탐색 구조에서 다시 열 수 있는 엔트리로 노출  
- 콜렉션 재사용성 유지  
  - 동일 조건으로 결과가 재현 가능하도록, 조건 정의의 표현을 일관되게 유지

#### **성공 상태**

- 조건이 명확히 표현되고, 동일 조건으로 결과가 재현 가능한 상태  
- 저장된 콜렉션이 탐색 구조 UI 상에서 일관된 위치에 노출되어, 이후 동일하게 접근 가능한 상태

## **CF04. Start Chat from Page**

#### **목표**

- 페이지 단의 탐색 흐름에서 채팅 기반 작업으로 자연스럽게 전환할 수 있게 한다.  
- 사용자의 입력과 현재 페이지 및 선택 상태 등의 콘텍스트를 기반으로, 이후 대화에서 일관되게 참조할 초기 작업 범위를 준비한다.

#### **시작 조건**

- 채팅 입력 필드에서 새 채팅 세션의 요청이 제출된 경우  
  - 우측 채팅 패인에서 메시지 입력 후 제출  
  - 커맨드 팔레트를 통한 자연어 명령어 제출  
  - 기타 채팅 입력 인터페이스를 통해 시작

#### **핵심 동작**

- 활용 가능한 모든 작업 맥락을 수집  
  - 현재 활성화된 페이지, 경로, 콜렉션 필터, 선택한 엔트리, 사용자 정의 콘텍스트 등  
- 수집된 작업 맥락을 기준으로, 해당 채팅에서 다룰 초기 작업 범위를 정의  
- 정의된 작업 범위는 이후 흐름에서 일관된 참조가 될 수 있도록 유지

#### **성공 상태**

- 새 채팅 세션이 생성되고, 해당 세션에 연결된 초기 작업 범위가 정의되어 보이는 상태  
- 이후 동일 세션 내 요청에서, 해당 작업 범위를 참조∙활용∙갱신 가능한 상태
