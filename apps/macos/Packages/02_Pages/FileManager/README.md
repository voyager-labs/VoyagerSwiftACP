# VoyagerPagesFileManager

File Manager 페이지 패키지. 사이드바, 인스펙터, 콘텐츠 페인, 윈도우 명령 라우팅을 포함한다.

### Contract Policy Reference

이 맵은 `file_manager_window_contract.toml`의 다음 정책을 기준으로 분류했다:

- `window_commands_apply_to_active_window = true`
- `open_window_creates_new_workspace_session = true`
- `close_window_preserves_other_windows = true`
- `quit_terminates_all_windows = true`
- `pane_width_clamped_to_allowed_range = true`
- `hidden_sidebar_drawer_is_transient = true`
- `sidebar_and_inspector_visibility_are_independent = true`
