# **UC01. 디렉토리를 브라우징하며 필요한 파일 열기**

1. ## **Summary**

   1. ### **One-line Definition**

- 현재 폴더의 엔트리를 브라우저처럼 탐색하고, 원하는 파일을 빠르게 찾아 열어 작업을 시작하는 기본 흐름

  2. ### **Purpose** 

- 사용자가 Finder 대신 Voyager를 열었을 때, 폴더를 탐색하고 필요한 파일을 여는 가장 기본적인 흐름을 안정적으로 제공하기 위함  
- 디렉토리 페이지에서 스크롤, 정렬, 간단한 필터, 미리보기, 열기까지의 경험을 하나의 플로우로 정리해 이후 UC02 정돈, UC03 콜렉션, UC05 이후 채팅 기반 작업의 출발점이 되도록 함  
- 키보드, 마우스와 같은 조작 방식과 무관하게 최소한 만족해야 하는 “기본 브라우징 사용성 기준”을 정의하기 위함

2. ## **Scope**

   1. ### **In-Scope**

- 파일 매니저 윈도우 내에서 특정 디렉토리 페이지를 열고, 같은 탭 안에서 상·하위 폴더를 이동하는 동작  
- 현재 디렉토리의 엔트리를 다양한 엔트리 뷰 형태로 나열하고, 스크롤/포커스 이동/단일/다중 선택을 통해 탐색하는 동작  
- 이름, 수정일, 타입, 크기 등 프로퍼티 기준으로 정렬을 변경하는 동작  
- 단일 또는 다중 선택된 엔트리를  
  - 기본 앱으로 열기  
  - “다른 앱으로 열기”와 같은 대체 앱 선택 후 열기  
  - 미리보기(Quick Look 또는 내장된 프리뷰) 호출  
- 디렉토리브라우징 히스토리를 사용하는 네비게이션 동작  
  - 뒤로·앞으로 이동  
  - 상위 폴더로 이동  
  - 부모 디렉토리 열기

  2. ### **Out-of-Scope**

- 엔트리 구조·메타데이터 변경 작업  
  - 이동, 복제, 삭제, 이름 변경, 태그 편집 등  
  - 대량 정리·아카이브 작업  
    → UC02에서 다룸  
- 여러 폴더·드라이브 범위를 넘나드는 검색 및 콜렉션 구성  
  - 조건 기반 콜렉션 생성  
  - 워킹셋을 콜렉션으로 승격  
    → UC03, UC04, UC06에서 다룸  
- 채팅과 결합된 작업  
  - 현재 폴더를 컨텍스트로 채팅 시작  
  - 대화에서 제안된 파일을 열거나 정리하는 흐름  
    → UC05에서 다룸  
- 스토리지·OS 레벨 관리  
  - 네트워크 드라이브/외장 디스크 마운트·언마운트  
  - 파일 시스템 권한 변경, 공유 설정 등

3. ## **Flow**

   1. ### **Representative scenario**

- 사용자는 Voyager를 열고, 사이드바의 탭 목록에서 탭을 선택해 해당 탭이 보고 있던 디렉토리 페이지를 활성화한다  
- 폴더 안에는 피치덱, 지표 시트, 리서치 PDF, 메모 파일 등이 섞여 있어 최근에 작업한 파일을 빨리 찾고 싶다.  
- 정렬을 수정일 내림차순으로 바꾸고, 리스트를 스크롤하며 파일 이름과 수정일을 훑어본다.  
- 후보가 되는 파일에서 스페이스바로 미리보기를 열어 실제 내용이 맞는지 확인한다.  
- 열어야 할 파일을 여러 개 선택하고, 한 번에 연다.  
- 필요한 파일이 각 앱에서 열리고, Voyager 디렉토리 페이지는 선택 상태와 스크롤 위치를 유지해 추가로 다른 파일을 열 수 있다.

### 

  2. ### **Variations**

- Variation A: 상위·형제 디렉토리로 이동하며 연속 탐색  
  - 사용자는 한 디렉토리에서 Happy Path와 동일하게 최근 작업 파일을 찾고 연 뒤, 경로 바나 단축키로 상위 또는 형제 디렉토리로 이동한다.  
  - 새로 열린 디렉토리에서도 동일하게 정렬을 수정일 내림차순으로 바꾸고, 리스트를 스크롤·미리보기·선택·열기하는 패턴을 반복한다.  
  - 여러 디렉토리를 오가면서, 각 디렉토리에서 최근 작업 파일을 빠르게 찾고 열 수 있다.  
- Variation B: 여러 탭에서 병렬 디렉토리 브라우징  
  - 사용자는 현재 디렉토리 뷰를 유지한 채, 다른 디렉토리를 새 탭으로 열어 두 개 이상 디렉토리를 병렬로 브라우징한다.  
  - 각 탭은 정렬 상태·선택 상태·스크롤 위치를 독립적으로 유지하고, 탭을 전환할 때마다 직전 상태를 그대로 복원한다.  
  - 사용자는 탭 간을 오가며 서로 다른 디렉토리의 최근 작업 파일을 비교·열어보는 식으로 작업을 이어간다.

  3. ### **Exceptions**

- Permission error  
  - OS 권한 등의 이유로 특정 엔트리에 접근할 수 없는 경우, 해당 엔트리는 엔트리 리스트에 표시하지 않고, 접근 가능한 엔트리만 브라우징·열기 대상이 되도록 한다.  
  - 디렉토리 전체에 대한 접근이 실패하는 경우에는 OS가 제공하는 기본 에러(예: “권한이 없습니다”)를 그대로 노출하고, 상위 디렉토리나 다른 탭으로 돌아갈 수 있도록 한다.
