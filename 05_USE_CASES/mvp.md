1. ## **Summary**

   1. ### **One-line Definition**

- 채팅 중 사용자가 제출한 메시지를 시스템이 검색 의도로 분류한 경우, 해당 메시지와 현재 컨텍스트를 바탕으로 콜렉션 필터 초안을 생성해 표시하고, 워킹셋 프리뷰로 결과를 검증한 뒤 콜렉션 필터를 확정해 최종 결과 워킹셋을 표시하는 검색 분기 흐름

  2. ### **Purpose**

- 사용자가 새 채팅을 시작하거나 대화를 이어가던 중 제출한 메시지가 검색 의도로 분류되면, 별도의 검색 UI 전환 없이 동일한 채팅 흐름에서 엔트리 탐색을 즉시 시작할 수 있도록 하기 위함  
- 검색 실행 전에 콜렉션 필터 초안을 생성·표시하고 워킹셋 프리뷰로 결과를 검증하게 해, 조건 해석과 결과의 연결을 사용자가 이해할 수 있도록 하고 탐색 신뢰도를 높이기 위함  
- 콜렉션 필터를 확정한 뒤 결과를 워킹셋으로 일관되게 남겨, 후속 메시지로 조건을 보정하며 재탐색하거나 이후 워킹셋 기반 플로우(질의·대화, 저장, 실행)로 자연스럽게 이어지도록 하기 위함

2. ## **Scope**

   1. ### **In-Scope**

- 채팅 메시지에서 검색 분기 진입  
  - 사용자가 새 채팅을 시작하거나 기존 채팅을 이어가며 메시지를 제출  
  - 시스템이 메시지를 의도로 분류했고, 그 결과가 “검색”인 경우  
- 콜렉션 필터 초안 생성 및 표시  
  - 메시지와 현재 컨텍스트를 바탕으로 콜렉션 필터 초안을 구성  
  - 탐색 범위는 컨텍스트 우선 적용(예: 현재 선택된 스토리지, 열려 있는 뷰/콜렉션, 사용자가 지정한 제한)  
  - 조건은 키워드, 기간, 타입/확장자, 경로 단서, 태그/즐겨찾기, 커스텀 프로퍼티 등으로 구조화  
  - 생성된 콜렉션 필터 초안을 사용자가 확인 가능한 형태로 채팅 UI에 표시  
- 워킹셋 프리뷰 제공  
  - 콜렉션 필터 초안을 실행해 결과를 평가하고 프리뷰를 제공  
  - 사용자가 프리뷰를 기반으로 조건/탐색 범위를 직접 수정할 수 있게 함  
- 콜렉션 필터 확정  
  - 사용자가 “확정” 액션으로 현재 턴의 콜렉션 필터를 확정  
  - 확정 이후 후속 메시지로 보정이 발생하면, 새 초안 생성 → 프리뷰 → 확정 사이클로 갱신  
- 결과 워킹셋 표시 및 확장  
  - 확정된 콜렉션 필터 결과를 워킹셋으로 생성해 채팅 메시지에 표시  
  - 사용자가 워킹셋을 메인 뷰로 확장해 결과 리스트를 확인  
  - 엔트리 열기/미리보기/정렬 등 기본 탐색 동작은 UC01의 동작을 재사용

  2. ### **Out-of-Scope**

- 검색 결과(워킹셋)를 대상으로 한 엔트리 변경∙삭제 등 정돈 작업  
  - 이름 변경, 이동, 복제, 삭제, 태그/라벨 편집, 커스텀 프로퍼티 값 편집 등  
  - 채팅에서 실행을 제안하고 승인받아 수행하는 흐름 포함  
     → UC02, UC06에서 다룸  
- 콜렉션을 직접 구성∙편집하는 플로우  
  - 스코프·조건을 조합해 규칙 기반 콜렉션을 만들고 저장/수정하는 작업  
     → UC03에서 다룸  
- 검색 결과 워킹셋을 콜렉션으로 저장/승격하는 플로우  
  - 예: “지금 결과를 콜렉션으로 저장”  
     → UC07에서 다룸  
- 검색이 아닌 채팅 작업  
  - 지정한 컨텍스트에서의 질의∙대화(요약, 비교, 정리, 초안 작성 등)  
     → UC05에서 다룸

3. ## **Flow**

   1. ### **Representative scenario**

- 사용자는 새 채팅을 시작하거나 기존 채팅을 이어가며 현재 다루고 싶은 대상에 대한 단서로 구성된 자연어 메시지를 제출한다.   
- 시스템은 해당 메시지를 검색 의도로 분류하고, 현재 컨텍스트를 반영해 콜렉션 필터 초안을 생성한 뒤 채팅에 표시한다.  
- 사용자는 표시된 콜렉션 필터 초안을 확인하고, 필요하면 직접 조건을 조작하거나, 후속 메시지를 통해 조건을 보정한다.  
- 시스템은 생성된 콜렉션 필터를 기준으로 워킹셋 프리뷰를 제시하고, 사용자는 결과가 의도에 맞는지 확인한 뒤 필터를 확정한다.  
- 시스템은 확정된 콜렉션 필터 결과를 워킹셋으로 표시해 응답으로 반환한다.   
- 사용자는 워킹셋을 펼쳐 결과 리스트를 브라우징하며 필요한 엔트리를 연다.

  2. ### **Variations**

- Variation A: 보정 없이 즉시 확정  
  - Happy Path와 동일하게 메시지를 제출한 뒤, 시스템이 표시한 콜렉션 필터 초안과 워킹셋 프리뷰 확인  
  - 사용자는 초안이 의도와 일치한다고 판단하여 조건을 수정하지 않고 곧바로 필터를 확정  
  - 시스템이 해당 필터에 따른 검색 결과 워킹셋 생성해 반환  
- Variation B: 후속 메시지로 점진 보정  
  - Happy Path의 Step 3-4에서 사용자는 프리뷰 결과를 보고 포함/제외 단서를 후속 메시지로 추가  
  - 시스템은 새 메시지를 반영해 콜렉션 필터 초안을 갱신해 다시 표시하고, 갱신된 필터 기준으로 워킹셋 프리뷰를 반복 제공  
  - 사용자는 충분히 좁혀졌다고 판단하는 시점에 필터를 확정  
  - 시스템이 해당 필터에 따른 검색 결과 워킹셋 생성해 반환  
- Variation C: 필터 UI 조작으로 빠른 보정  
  - 사용자는 후속 메시지를 보내지 않고, 표시된 콜렉션 필터 초안에서 조건 토큰/칩을 직접 수정·제거·제외  
  - 시스템은 조작 내용을 즉시 반영해 콜렉션 필터 초안과 워킹셋 프리뷰를 갱신  
  - 사용자는 몇 차례 비교 후 필터를 확정  
  - 시스템이 해당 필터에 따른 검색 결과 워킹셋 생성해 반환  
- Variation D: 프리뷰에서 엔트리를 열어 검증  
  - 사용자는 프리뷰 단계에서 충분한 후보가 제공되어, 필터를 확정하기 전에 결과가 의도에 맞는지 빠르게 검증하고 싶음  
  - 사용자는 워킹셋 프리뷰에 포함된 후보 엔트리를 열어 확인한 뒤, 다시 프리뷰로 돌아와 조건 보정 또는 확정을 진행  
  - 시스템은 프리뷰 상태를 유지한 채 엔트리 열기/미리보기 동작을 허용하고, 사용자가 돌아오면 동일한 콜렉션 필터 초안과 프리뷰를 이어서 표시  
  - 사용자가 필터를 확정하면, 시스템이 해당 필터에 따른 검색 결과 워킹셋 생성해 반환

  3. ### **Exceptions**

- Intent classification uncertain  
  - 검색 의도/질의∙대화 의도/실행 의도 경계 모호  
  - 콜렉션 필터 초안 생성 전, 최소 단서 1-2개 추가 질문  
  - 검색 의도 확정 시, 해당 메시지 기준으로 콜렉션 필터 초안 생성 및 표시  
- Filter draft conflict / ambiguous constraints  
  - 기간·타입·키워드 단서 상충 또는 컨텍스트 제한과 조건 충돌  
  - 콜렉션 필터 초안 상태를 “불완전”으로 표시  
  - 충돌 지점 요약 표시  
  - 조건 조작 또는 후속 메시지로 보정 유도  
- Unsupported condition / unresolvable filter  
  - 미지원 프로퍼티·연산 포함으로 초안 완성 불가  
  - 지원 가능한 조건만으로 축소한 초안 제안  
  - 제외된 조건 목록 및 영향 요약 표시  
  - 대체 입력 유도  
- Zero result / too few results  
  - 워킹셋 프리뷰 결과 0건 또는 극소  
  - 프리뷰 내 “결과 없음” 상태 표시  
  - 콜렉션 필터 초안 편집 상태 유지(조건 조작, 후속 메시지 입력 대기)  
  - 사용자가 초안을 보정하면, 시스템은 동일 프리뷰를 재계산해 갱신  
- Too many results  
  - 워킹셋 프리뷰 결과 과다  
  - 대표 샘플 우선 제시  
  - 결과 과다 원인 요약 표시(조건 부족, 단서 약함)  
  - 좁히기 유도: 기간, 타입, 키워드, 제외 단서 추가  
  - 보정된 초안 기준으로 프리뷰 반복 갱신  
- Long-running preview / delayed response  
  - 프리뷰 계산 또는 워킹셋 생성 지연  
  - 진행 상태 표시  
  - 사용자 선택지 제공: 대기, 조건 좁히기, 프리뷰 재시도  
  - 지연 완화용 대표 보정 제안: 기간 축소, 타입 제한, 제외 단서 추가  
- Cancelled by user  
  - 프리뷰 생성 또는 워킹셋 생성 진행 중 사용자 취소  
  - 진행 중 작업 중단  
  - 마지막 콜렉션 필터 초안 상태 유지  
  - 동일 초안으로 프리뷰 재시도 또는 조건 보정 계속 가능  
- Indexing incomplete / search degraded  
  - 탐색 범위 내 인덱싱 미완료 또는 검색 품질 저하 가능  
  - 프리뷰에 “결과가 불완전할 수 있음” 표시  
  - 선택지 제공: 현재 가능한 범위로 진행, 인덱싱 완료 후 재시도, 미완료 범위 제외  
- Permission error / access denied  
  - 파일 시스템 권한, 클라우드 동기화 상태, 파일 잠금 등으로 일부 엔트리 접근 불가  
  - 해당 엔트리 결과에서 제외  
  - “권한 문제로 일부 제외됨” 요약 표시(가능하면 규모 포함)  
- Storage unavailable  
  - 탐색 범위 포함 스토리지 연결 해제 상태(외장/네트워크/클라우드)  
  - 해당 범위 제외한 프리뷰 우선 제공  
  - 연결 필요 상태 표시  
  - 스토리지 복구 시 동일 초안 기준으로 프리뷰 갱신 가능  
- Result changed between preview and confirm  
  - 프리뷰 확인 후 확정 전후, 엔트리 이동·삭제·동기화 등으로 결과 변동  
  - 확정 시점에 결과 재계산  
  - “일부 결과가 업데이트됨” 표시  
  - 더 이상 접근 불가 항목에 사유 표시(위치 변경, 삭제, 동기화 상태)
