1. ## **Summary**

   1. ### **One-line Definition**

* 사용자가 디렉토리·선택 엔트리·콜렉션·워킹셋 등을 컨텍스트로 두고, 해당 컨텍스트를 바탕으로 질문하고 답을 얻으며(요약·비교·정리·초안 작성 등) 작업을 이어가는 채팅 기반 질의∙대화 흐름

  2. ### **Purpose**

* 사용자가 지금 작업에 필요한 자료를 컨텍스트로 잡아두고, 파일을 하나씩 열어보지 않아도 핵심 내용을 빠르게 파악할 수 있도록 하기 위함  
* 동일 컨텍스트를 유지한 채 후속 질문을 이어가며, 요약·비교·정리·초안 작성 같은 지식 작업을 끊김 없이 진행할 수 있도록 하기 위함  
* 응답이 어떤 엔트리를 근거로 생성되었는지 확인할 수 있게 해, 사용자가 결과를 검증하고 수정 요청을 정확히 할 수 있도록 하기 위함  
* 질의·대화 결과에서 자연스럽게 작업에 필요한 엔트리 묶음이 정리되도록 하고, 이를 워킹셋으로 남겨 이후 콜렉션 저장(UC06)이나 변경 작업(UC06)으로 이어질 수 있도록 하기 위함

2. ## **Scope**

   1. ### **In-Scope**

* 단일 채팅 세션에서 질의∙대화 요청 처리  
  * 컨텍스트를 바탕으로 질문에 답변  
  * 핵심 추출, 요약, 비교, 분류, 정리, 설명  
* 산출물 생성(비변경)  
  * 미팅 스크립트, 업데이트 메모, 체크리스트, 비교표, 간단한 리포트 문단 등 텍스트 산출물 생성  
  * 생성된 산출물을 후속 메시지로 보정(톤, 길이, 구조, 포함/제외 항목 등)  
* 컨텍스트 구성 및 갱신  
  * 디렉토리, 선택 엔트리, 콜렉션, 워킹셋을 채팅 컨텍스트로 추가·제거·교체  
  * 채팅 UI에서 현재 컨텍스트 상태(대상, 엔트리 개수 등)를 확인 가능하게 표시  
* 근거 기반 응답 제공  
  * 어떤 엔트리를 참고했는지 확인 가능한 형태로 근거(참조 엔트리) 정보를 제공  
  * 근거가 부족하거나 모호한 경우, 필요한 추가 단서를 요청하거나 컨텍스트 조정을 유도  
* 워킹셋 형성 및 재사용  
  * 질의∙대화 과정에서 중요하다고 판단된 엔트리 묶음을 워킹셋으로 유지  
  * 워킹셋을 메인 뷰로 펼쳐 확인하고, 포함/제외를 조정해 다음 질문의 대상으로 재사용  
* 후속 플로우 연결  
  * 워킹셋을 콜렉션으로 저장하는 흐름은 UC06으로 연결  
  * 파일 변경∙삭제 등 실행이 필요한 요청은 UC06으로 연결  
  * 필요 시 파일 열기/미리보기는 UC01의 동작을 재사용

  2. ### **Out-of-Scope**

* 엔트리 “찾기” 자체  
  * 자연어로 엔트리 묶음을 찾고, 탐색 범위를 확장해 워킹셋을 구성하는 검색 플로우  
    → UC04에서 다룸  
* 파일 변경∙삭제 등 실행 작업  
  * 이름 변경, 이동, 삭제, 태그/라벨 편집, 대량 정리 실행, 승인/적용 플로우  
    → UC06에서 다룸  
* 콜렉션 규칙 설계·편집  
  * 범위와 조건을 조합해 규칙 기반 콜렉션을 만들고 저장/수정하는 플로우  
    → UC03에서 다룸  
* 파일 본문 직접 편집 및 저장  
  * 문서/슬라이드/코드 등 콘텐츠 편집 및 저장은 외부 앱 또는 별도 Use Case  
* 자동화/백그라운드 실행  
  * 주기 실행, 정책 기반 일괄 정리, 자동 실행 플로우는 자동화 Use Case로 분리

3. ## **Flow**

   1. ### **Representative scenario**

* 사용자는 특정 업무(예: 투자자 업데이트, 리서치 정리, 월간 결산)를 진행 중이며, 관련 문서·시트·PDF·스크린샷이 여러 위치에 흩어져 있다.  
* 사용자는 현재 보고 있는 디렉토리, 이미 선택한 엔트리, 저장된 콜렉션, 또는 이전에 만들어 둔 워킹셋을 컨텍스트로 추가해 채팅을 시작한다.  
* 사용자는 “이 컨텍스트를 바탕으로 핵심만 요약해줘”, “서로 다른 자료에서 공통 주장만 뽑아줘”, “이번 달 업데이트 문단 초안 써줘”처럼 질의∙대화를 이어간다.  
* 시스템은 컨텍스트를 근거로 답변과 산출물을 생성하고, 사용자가 후속 메시지로 조건과 형식을 조정하며 결과를 점진적으로 다듬는다.  
* 사용자에게 중요한 엔트리들이 워킹셋으로 정리되고, 이후 필요하면 콜렉션으로 저장하거나(UC06) 실행이 필요한 변경 작업으로 전환한다(UC06).

  2. ### **Variations**

* Variation A: 디렉토리를 컨텍스트로 두고 요약·정리  
  * 특정 폴더를 열어둔 상태에서 해당 디렉토리를 컨텍스트로 시작해, 폴더 내부 자료만 기반으로 질문을 이어간다.  
* Variation B: 선택 엔트리 소수로 정밀 비교  
  * 몇 개의 핵심 파일만 선택해 컨텍스트로 추가한 뒤, 차이점 비교, 핵심 추출 같은 정밀 질의를 수행한다.  
* Variation C: 콜렉션을 컨텍스트로 두고 산출물 작성  
  * 규칙 기반 또는 저장된 콜렉션을 컨텍스트로 두고, 업데이트 메모/보고 문단/스크립트 초안을 반복 보정한다.  
* Variation D: 워킹셋을 컨텍스트로 두고 후속 질의  
  * 이전 흐름에서 확정된 워킹셋을 컨텍스트로 삼아, 같은 자료 묶음으로 추가 질문을 이어간다.

  3. ### **Exceptions**

* 근거 부족  
  * 컨텍스트 내에 질문에 답할 만한 자료가 부족한 경우, 필요한 단서(기간, 타입, 키워드, 대상 문서)를 되묻는다.  
* 컨텍스트 과대  
  * 컨텍스트에 엔트리가 너무 많아 요약/정리가 거칠어질 경우, 사용자가 좁힐 수 있도록 대표 필터(기간, 타입 등)를 제안한다.  
* 접근/권한 문제  
  * 일부 엔트리가 권한 또는 동기화 상태 문제로 읽을 수 없는 경우, 해당 항목을 제외하고 제외 사유를 요약한다.  
* 인덱싱/추출 미완료  
  * 텍스트 추출/인덱싱이 완료되지 않은 항목이 포함된 경우, 결과가 불완전할 수 있음을 알리고 가능한 범위에서 답변을 생성한다.  
* 근거 충돌  
  * 서로 다른 문서가 상충되는 내용을 담는 경우, 단일 결론으로 단정하지 않고 관측된 차이를 정리해 제시한다.
