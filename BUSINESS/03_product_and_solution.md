# Product and Solution

## Product Thesis

쌓이는 파일과 노트를 재사용 가능한 지식 자산으로 바꾸는 AI 파일 워크스페이스, 보이저(Voyager)

## Solution Narrative

기존 폴더 중심 파일 관리 위에 시스템 속성, 사용자 정의 속성, 관계, AI 에이전트, 콜렉션 기반 자동화를 더해 파일과 노트를 재사용 가능한 지식 자산으로 다룬다. 사용자는 파일을 고정된 위치가 아니라 업무 맥락과 조건의 집합으로 다루고, 그 맥락 위에서 탐색, 정돈, 요약, 실행, 자동화를 이어간다.

## Before / After

| Before                                         | After                                                    |
| ---------------------------------------------- | -------------------------------------------------------- |
| 파일명과 저장 경로를 기억해야 한다.            | 파일 기본 속성과 사용자 정의 속성으로 맥락을 누적한다.   |
| 파일이 하나의 폴더 배치로만 강제된다.          | 파일은 여러 조건 기반 콜렉션에 동시에 포함될 수 있다.    |
| 폴더 정돈 규칙이 시간이 갈수록 붕괴한다.       | 명시적 속성 조건과 자동화 규칙이 누적된다.               |
| 후속 작업은 별도 앱과 AI 도구로 전환해야 한다. | 파일 관리자 안에서 에이전트 실행과 후속 작업을 이어간다. |

## Core Capabilities

- 시스템 속성과 사용자 정의 속성을 함께 활용한다.
- 자연어 요청을 파일명, 확장자, 위치 등 검색 가능한 속성 조건으로 구조화한다.
- 속성 조건을 통해 콜렉션을 정의하고, 파일을 이동하지 않아도 조건에 맞는 파일을 동적으로 갈무리한다.
- 탭 기반 워크스페이스로 여러 파일 작업을 병렬로 열어두고 작업 맥락을 유지한다.
- 채팅 패널을 통해 현재 바라보는 파일 집합을 읽고 요약, 탐색, 정돈 등 후속 작업을 실행한다.
- 콜렉션 기준 트리거를 설정해 파일 작업과 에이전트 호출을 자동화한다.

## AI Usage

- 속성 후보 제안: 파일 내용과 현재 속성 구조, 사용 맥락을 분석해 적절한 속성 후보를 제안한다.
- 자연어 조건 변환: 사용자 요청을 파일 범위, 속성, 연산자, 조건으로 변환해 콜렉션 생성 또는 파일 탐색에 사용한다.
- 의미 기반 파일 매칭: 파일 내용, 속성, 사용자 요청의 의미적 유사도를 계산해 관련 파일 후보를 탐색·추천한다.
- 작업 의도 분류: 사용자 자연어 요청을 탐색, 정돈, 요약, 질의응답, 생성 등 파일 관리 작업 유형으로 분류한다.
- 대화형 파일 에이전트: 현재 파일 집합과 작업 맥락을 활용해 후속 작업을 처리한다.

## Current Implementation Scope

- 시스템 속성 기반 콜렉션 정의 기능을 알파 테스트 중이다.
- 자연어 콜렉션 생성 기능을 구현했다.
- 파일 속성 파싱·인덱싱과 자연어 속성 조건 변환은 핵심 검증 범위다.
- 대화형 파일 관리 에이전트는 MVP 유료화와 반복 사용성 검증의 핵심 기능으로 준비 중이다.
- 콜렉션 기반 자동화는 상위 과금 모델 검증을 위한 후속 기능으로 개발한다.

## Product Outcome

사용할수록 파일 체계가 자산으로 누적되어, 다음 파일 탐색·정돈·실행 작업 비용을 줄인다.
