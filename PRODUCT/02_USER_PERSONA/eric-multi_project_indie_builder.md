## Context

- 핵심 상황  
  - 프로젝트 A, B, C를 오가며 작업을 전환할 때, 각 제품의 최신 문서, 프로모션 에셋(스크린샷, 데모 비디오), 코드들이 폴더 곳곳에 흩어져 있음

2. ### 다양한 채널로의 마케팅 파일 공유 및 재사용

- 핵심 상황

## Pains

1. ### 산재된 파일로 인한 공유 및 재사용의 어려움

- "외부로 공유할 최신 데모 영상이 어디 있었지?" 특정 프로젝트별 파일이 여기저기 흩어져 있어, 필요할 때 구조를 잡기 어렵고 매번 재수집해야 함  
- 버전 관리가 안 된 스크린샷과 파일 더미 속에서 최종본(Final_Final)을 판별하기 모호해 실수가 발생함

2. ### 프로젝트 간 작업 맥락 단절

- 제품 A 개발을 하다가 제품 B의 문의를 처리하기 위해 맥락을 변경할 때, 해당 프로젝트의 참고 파일이나 기획 문서를 한눈에 꺼내보기 힘듦

## Goals

1. 여러 프로젝트의 산출물이 흩어져 있어도, 특정 프로젝트나 캠페인을 기준으로 관련 파일이 한 곳에 모여있는 느낌(가상의 구조)을 갖는 것  
2. 외부나 SNS에 에셋(스크린샷, 데모 영상 등)을 공유해야 할 때, 언제나 ‘가장 최신본’만 모여 있는 뷰를 통해 지체 없이 공유할 수 있는 상태
