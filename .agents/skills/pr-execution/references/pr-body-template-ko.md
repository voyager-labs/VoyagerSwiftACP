# PR 본문 템플릿 (한국어)

## 제목

- 형식: `[<Linear Issue ids...>] {PR 요약 주제}`
- 예시:
  - `[VOY-164] macOS 런타임의 로컬 백엔드 결합 제거 및 Helper/XPC 구조 정리`
  - `[VOY-164, VOY-201] 검색 convert-only 계약 정리 및 문서 동기화`

  - 대괄호에는 실제 Linear 이슈 ID만 넣습니다.

  - 본문의 변경 범위/커밋 목록과 제목 의도가 모순되면 안 됩니다.
