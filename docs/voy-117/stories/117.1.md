# Story 117.1 - VOYAGER_PROJECT_ROOT 전달 - Brownfield Addition

## User Story
As a 개발자(로컬 실행 사용자),
I want VoyagerHelper가 VOYAGER_PROJECT_ROOT를 정확히 인지하도록,
So that source 모드에서 backend 경로를 안정적으로 찾을 수 있다.

## Story Context

**Existing System Integration:**
- Integrates with: `HelperAppClient`, `Environment.findProjectRoot()`
- Technology: SwiftUI + TCA, AppKit(NSWorkspace), VoyagerHelper
- Follows pattern: TCA DependencyKey 기반 클라이언트 주입 패턴
- Touch points: `apps/macos/Voyager/Voyager/App/Clients/HelperAppClient.swift`,
  `apps/macos/Voyager/VoyagerHelper/Infrastructure/Environment.swift`

## Acceptance Criteria

**Functional Requirements:**
1. Voyager 실행 시 Helper 실행 환경에 `VOYAGER_PROJECT_ROOT`가 전달된다.
2. Helper는 `VOYAGER_PROJECT_ROOT`를 우선 사용해 source 모드 backend 경로를 찾는다.
3. `VOYAGER_PROJECT_ROOT`가 없을 때는 기존 fallback 로직이 그대로 동작한다.

**Integration Requirements:**
4. Helper 실행/감시 로직의 기존 동작은 변경되지 않는다.
5. Bundled 모드(Release)에서 동작에 영향이 없다.

**Quality Requirements:**
6. 로컬 dev 실행에서 backend 경로 탐지가 정상 동작한다.
7. 변경 전후 회귀 동작이 수동 QA로 확인된다.

## Technical Notes
- **Integration Approach:** `NSWorkspace.OpenConfiguration.environment`에 `VOYAGER_PROJECT_ROOT`를 포함해 Helper 실행.
- **Existing Pattern Reference:** `HelperAppClient.liveValue`의 환경 주입 흐름.
- **Key Constraints:** source/bundled 모드 모두 영향이 없어야 함.
