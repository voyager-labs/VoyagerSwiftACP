# Story 117.2 - Helper 종료 감지 및 재시작 정책 - Brownfield Addition

## User Story
As a 사용자,
I want Helper가 비정상 종료되더라도 자동으로 복구되길,
So that Voyager 사용 중 기능이 안정적으로 유지된다.

## Story Context

**Existing System Integration:**
- Integrates with: `AppLifecycleFeature`, `HelperAppClient` 종료 이벤트 스트림
- Technology: SwiftUI + TCA, AppKit(NSWorkspace)
- Follows pattern: TCA reducer에서 async stream 감시
- Touch points: `apps/macos/Voyager/Voyager/App/Features/AppLifecycleFeature.swift`,
  `apps/macos/Voyager/Voyager/App/Clients/HelperAppClient.swift`

## Acceptance Criteria

**Functional Requirements:**
1. Voyager 실행 중 Helper 종료 이벤트를 감지하면 backoff 정책에 따라 재실행한다.
2. backoff는 1s → 2s → 4s → 8s → 16s(최대 5회 재시도)로 적용한다.
3. 재시도 중에는 사용자에게 UI 알림을 노출하지 않고 로그만 남긴다.
4. 최대 재시도 초과 시 Voyager는 즉시 종료(Crash)된다.
5. Voyager 종료 시 Helper를 강제로 종료하지 않는다.

**Integration Requirements:**
6. Helper 재실행은 중복 실행을 방지한다.
7. 기존 앱 종료 흐름과 충돌하지 않는다.

**Quality Requirements:**
8. 재시도/종료 이벤트가 로그로 확인 가능하다.
9. 변경 전후 회귀 동작이 수동 QA로 확인된다.

## Technical Notes
- **Integration Approach:** Helper 종료 감지 루프에 backoff 및 최대 재시도 상태를 추가.
- **Existing Pattern Reference:** `AppLifecycleFeature`의 `.run` 감시 처리.
- **Key Constraints:** backoff/최대 재시도 정책은 고정값으로 적용.

## Risk and Compatibility Check

**Minimal Risk Assessment:**
- **Primary Risk:** 재시도 루프가 앱 응답성을 저하.
- **Mitigation:** backoff 간격 적용 및 최대 재시도 제한.
- **Rollback:** Helper 재시작 정책을 기존 단순 재시작 로직으로 복귀.

**Compatibility Verification:**
- [ ] No breaking changes to existing APIs
