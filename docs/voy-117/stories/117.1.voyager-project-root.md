# Story 117.1: VOYAGER_PROJECT_ROOT 전달

## Status
Draft

## Story
**As a** 개발자(로컬 실행 사용자),  
**I want** VoyagerHelper가 VOYAGER_PROJECT_ROOT를 정확히 인지하도록,  
**so that** source 모드에서 backend 경로를 안정적으로 찾을 수 있다.

## Acceptance Criteria
1. Voyager 실행 시 Helper 실행 환경에 `VOYAGER_PROJECT_ROOT`가 전달된다.
2. Helper는 `VOYAGER_PROJECT_ROOT`를 우선 사용해 source 모드 backend 경로를 찾는다.
3. `VOYAGER_PROJECT_ROOT`가 없을 때는 기존 fallback 로직이 그대로 동작한다.
4. Helper 실행/감시 로직의 기존 동작은 변경되지 않는다.
5. Bundled 모드(Release)에서 동작에 영향이 없다.
6. 로컬 dev 실행에서 backend 경로 탐지가 정상 동작한다.
7. 변경 전후 회귀 동작이 수동 QA로 확인된다.

## Tasks / Subtasks
- [ ] Helper 실행 환경에 `VOYAGER_PROJECT_ROOT` 주입 (AC: 1, 2)
  - [ ] Helper 실행 시 env 전달 경로 정리 (`HelperAppClient`)
- [ ] fallback 유지 확인 (AC: 3)
- [ ] Bundled 모드 영향 없음 확인 (AC: 5)
- [ ] 로컬 dev 회귀 QA 수행 (AC: 6, 7)

## Dev Notes
- `HelperAppClient.liveValue`에서 `NSWorkspace.OpenConfiguration.environment`로 Helper 실행 환경을 주입한다.
- `Environment.findProjectRoot()`는 `VOYAGER_PROJECT_ROOT`를 우선 사용하고, 없으면 기존 fallback을 사용한다.
- "source 모드"는 Helper가 `uv run dev|prod`로 로컬 backend를 실행하는 모드다.
- 스킴에서 `VOYAGER_PROJECT_ROOT`가 주입되고, 런타임에 Helper 실행 환경으로 전달된다.
- 참고: `docs/voy-117/epic.md#epic-goal`
- 참고: `docs/architecture/tech-stack.md#기술-요약`
- 참고: `docs/architecture/source-tree.md#실제-프로젝트-구조`
