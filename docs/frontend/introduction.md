# Introduction

이 문서는 Voyager의 사용자 경험 목표, 정보 구조(IA), 핵심 사용자 흐름, 및 시각/상호작용 사양을 정의합니다. 목적은 디자인과 프런트엔드 개발이 일관된 원칙과 구조 하에 진행되도록 돕는 것입니다.

## Overall UX Goals & Principles

- Target User Personas
  - Power User: 키보드 중심, 효율/속도 중시, 단축키 선호
  - Casual User: 명확한 안내, 쉬운 사용과 안전한 피드백 선호
  - Indie Founder/Developer: 문서형 워크플로, 로컬 우선, 프라이버시 민감

- Usability Goals
  - 5분 내 핵심 과업 학습
  - 키보드만으로 전 흐름 완결
  - 빠른 탐색/검색(지연 체감 최소화)
  - 로컬 중심·프라이버시 우선

- Design Principles
  - Clarity over cleverness
  - Progressive disclosure
  - Consistent patterns
  - Immediate feedback
  - System-first (macOS 기본 컴포넌트 우선)
  - Keyboard-first interactions
