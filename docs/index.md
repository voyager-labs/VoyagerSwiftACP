# Voyager Docs

이 앱 레포는 active engineering 문서, legacy reference 문서, canonical product 문서를 분리한다.

## Active documentation

- [Engineering docs](canonical/ENGINEERING/index.md) — canonical submodule의 active 기술 결정, 구현 흐름, 코드/테스트 topology.
- [Canonical docs](canonical/README.md) — 문서 submodule이 관리하는 제품, 비즈니스, 웹사이트, 그로스, feature-spec SSOT.

## Legacy reference

- [Legacy docs](legacy/index.md) — 이전 architecture, features, macOS, integration, development, testing, deployment, troubleshooting 문서.

Legacy 문서는 stale일 수 있다. 새 기술 문서는 `canonical/ENGINEERING/`에 작성하고, legacy의 유효한 내용은 필요할 때 active engineering 문서로 이관한다.
