# Story 1.3: Beta Access Step (Mock Verification)

## Status

Ready

## Story

**As a** 베타 사용자,  
**I want** `Beta Access` 단계에서 이메일/토큰을 입력하고 모킹된 검증 결과를 확인하며,  
**so that** 실제 서버 연동 전에도 온보딩 게이팅/UX를 검증할 수 있다.

## Acceptance Criteria

1. `Beta Access` 스텝은 이메일/토큰 입력 필드를 제공하고 입력값으로 검증을 시도한다.
2. 검증 결과는 `Active` / `Not Active` / `Check failed` 상태로 표시된다.
3. `Not Active` 상태는 reason code로 구분되며, 사유별 가이드를 제공한다: `missingInput`, `mismatch`, `tokenAlreadyRegistered`.
4. 하드코딩된 시나리오 순환은 `BetaAccessFeature.State`의 `scenarioIndex`로 관리하며, 이메일/토큰이 모두 입력된 검증 시도에만 인덱스를 1씩 증가(모듈러 4)한다. 순환 순서는 `Mismatch` → `Token already registered` → `Check failed` → `Active` (반복).
5. `Active`가 되기 전까지 `Next`는 비활성화되고, `Active`가 되면 상단 요약 뱃지(`Beta`)가 `Granted`로 갱신된다.
6. `Check failed` 상태는 일시적 검증 실패로 간주하고 `Retry`로 재시도할 수 있으며, 재시도 시 다음 순환 결과로 진행된다(원인/다음 행동 가이드 제공).

  - `status`: `active` | `notActive` | `checkFailed`
  - `reason`: `missingInput` | `mismatch` | `tokenAlreadyRegistered` | `none`
  - `scenarioIndex`: 0~3 순환, 유효 입력 시에만 증가

### UX Decisions

- 입력 필드 라벨: `Email`(이메일), `Token`(토큰)
- 플레이스홀더: `email@example.com`(이메일 예시), `Paste your token here`(토큰을 여기에 붙여넣기)
- 도움말 문구: “Enter the email and token from your invitation email.”(초대 메일에 있는 이메일과 토큰을 입력해 주세요.)
- 토큰 입력은 기본 마스킹(`SecureField`)으로 처리하고 붙여넣기 사용을 전제로 한다.
- 검증 CTA는 상태에 따라 라벨을 전환한다: 기본은 `Check`(확인), `Check failed` 상태에서는 `Retry`(재시도).
- CTA는 이메일/토큰이 모두 입력될 때만 활성화한다.
- `onAppear`에서 입력 유효성만 먼저 검사하고, 미입력일 경우 `Not Active` + `missingInput` 가이드를 노출한다.
- 상태 라벨은 영문(`Active` / `Not Active` / `Check failed`)으로 노출하며, 문서에는 한국어 번역을 병기한다.
- 검증 중에는 스피너를 표시하고 CTA/입력을 비활성화한다.

### UX Copy (Draft)

- `Active`
  - 메시지: “Your beta access is confirmed. You can continue to the next step.”(베타 접근이 확인되었습니다. 다음 단계로 진행할 수 있어요.)
- `Not Active` + `missingInput`
  - 메시지: “Please enter both your email and token. Check your invitation email for the details.”(이메일과 토큰을 모두 입력해 주세요. 초대 메일에서 정보를 확인해 주세요.)
- `Not Active` + `mismatch`
  - 메시지: “That email and token don’t match. Please double-check the invitation email.”(이메일과 토큰이 일치하지 않아요. 초대 메일 정보를 다시 확인해 주세요.)
- `Not Active` + `tokenAlreadyRegistered`
  - 메시지: “Each token can be registered to one device only. If you want to switch devices, please contact the invite owner.”(토큰은 하나의 디바이스에만 등록할 수 있어요. 기기를 변경하려면 초대 담당자에게 연락해 주세요.)
- `Check failed`
  - 메시지: “We couldn’t verify right now. Check your connection and try again.”(지금 확인할 수 없어요. 네트워크 상태를 확인한 뒤 다시 시도해 주세요.)

### Testing

  - Missing email/token → Not Active + guidance
  - Mismatch → Not Active + guidance
  - Token already registered → Not Active + guidance
  - Check failed + Retry loop
  - Active → Next enabled + badge granted
