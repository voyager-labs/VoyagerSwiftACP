## Story 1.2: Onboarding Step State Machine + Persistence/Resume

## Status

Review

**As a** 신규 사용자,
**I want** 온보딩 진행 상태가 저장되고 앱 재실행 시 마지막 유효 스텝에서 재개되며,
**so that** 앱이 종료/크래시되어도 온보딩을 다시 처음부터 반복하지 않고 빠르게 완료할 수 있다.

## Acceptance Criteria

1. 온보딩은 `Welcome → Beta Access → Permissions(FDA) → Indexing Preset(OBT) → Complete` 순서로 진행된다.
2. `Back` / `Next`로 스텝 이동이 가능하며, 스텝의 완료 조건을 만족하지 않으면 `Next`는 비활성화된다.
3. 앱 재실행 시 미완료 세션이 있으면 마지막 유효 스텝에서 재개되고 “이전에 중단된 온보딩을 이어서 진행합니다.” 안내가 표시된다.
4. 저장된 진행 지점이 현재 온보딩 버전과 불일치하거나 상태 로드에 실패하면, 온보딩은 안전하게 초기화되어 `Welcome`부터 시작한다.
5. 온보딩 윈도우 닫기(빨간 버튼/⌘W) 시 “앱 종료 확인” 모달이 표시된다.
   - `Cancel`을 선택하면 온보딩이 유지된다.
   - `Quit`을 선택하면 앱이 종료되고, 다음 실행에서 온보딩이 재개된다.

## Dev Notes

- Depends on: Story 1.1 (Onboarding window is shown when required)
- UX/AC source: `docs/frontend/onboarding-window-spec.md#acceptance-criteria-locked-for-voy-111`
- Persistence schema (명시):
  - UserDefaults keys: `onboardingProgressVersion`, `onboardingCurrentStep`, `onboardingStepState`
  - `onboardingStepState`는 step id → 최소 상태(JSON)로 직렬화하여 저장
- Last valid step rule (명시): 저장된 step의 완료 조건이 불충족이면 이전 step으로 롤백, 모두 불충족이면 `Welcome`으로 초기화
- Resume banner: 스펙상 배너는 닫기 가능(닫아도 진행 상태는 유지)
- Stack notes:
  - macOS app is SwiftUI + TCA, with AppKit window bridging. [Source: `docs/architecture/tech-stack.md`]
  - Sources tree references window orchestration in `AppDelegate.swift`/`FileManagerWindowController.swift`. [Source: `docs/architecture/source-tree.md`]
- TCA composition guidance (non-negotiable for this epic):
  - Root reducer: `OnboardingFeature` (`@Reducer` + `@ObservableState`) owns step routing, `Back`/`Next`, and cross-step gating.
  - Step reducers: implement each step as its own TCA feature and compose them using `Scope`, mirroring existing patterns in the app (parent scopes into child).
  - Views: SwiftUI views should take `StoreOf<...>` and use bindings (`Binding(get:set:)`) or `WithViewStore` as already used in the app.
- Suggested code placement (aligned to existing structure):
  - Reducer/state: `apps/macos/Voyager/Voyager/Onboarding/Features/OnboardingFeature.swift`
