# Story 1.7: Onboarding Window Modern UI Refresh - Brownfield Addition

## Status
Draft

## Story Title
Onboarding Window Modern UI Refresh - Brownfield Addition

## User Story

As a 신규 사용자,
I want 온보딩 윈도우가 Raycast 스타일의 미니멀한 레이아웃과 현대적 비주얼로 정리되며 상단 인셋 바 내비게이션을 제공하고,
So that 초기 경험에서 신뢰감과 집중도를 높이고 다음 단계로 자연스럽게 이동할 수 있다.

## Story Context

**Existing System Integration:**

- Integrates with: `OnboardingView` + `OnboardingStepViews`
- Technology: SwiftUI + TCA (macOS)
- Follows pattern: 기존 온보딩 뷰 레이아웃/상태 바인딩 패턴 유지
- Touch points:
  - `apps/macos/Voyager/Voyager/Onboarding/Views/OnboardingView.swift`
  - `apps/macos/Voyager/Voyager/Onboarding/Views/OnboardingStepViews.swift`
  - `apps/macos/Voyager/Voyager/App/OnboardingWindowController.swift`
  - `docs/frontend/onboarding-window-modern-package.md`

## Acceptance Criteria

**Functional Requirements:**

1. 상단 히어로 타이틀 영역을 제거하고 좌/우 섹션 또는 중앙 정렬 기반 레이아웃으로 구성한다.
2. 상단 인셋 바를 추가한다: 좌측 `Back`, 중앙 도트 페이지네이션(5개), 우측 `Enter` 버튼(Primary).
3. `Enter`는 기존 `Next`와 동일 동작이며, `Next`가 비활성일 때 동일하게 비활성화된다.

**Integration Requirements:**

4. 기존 온보딩 스텝/상태머신/게이팅 로직은 변경하지 않는다.
5. 하단 `Back`/`Next` 내비게이션은 유지하되, 상단 인셋 바와 상태(활성/비활성)가 일치한다.
6. `OnboardingWindow`는 `visibleFrame` 기준 80% 크기를 기본으로 한다(최소 1100x720, 최대 1400x900 범위 내에서 clamp).

**Quality Requirements:**

7. 모션은 윈도우 fade-in만 적용한다(200~240ms, ease-out).
8. Accent 컬러 `#FC9A30` 적용이 Primary CTA/활성 스텝/진행률에 일관되게 반영된다.
9. 다크/라이트 모드 모두에서 대비/가독성 문제가 없다.

## Technical Notes

- **Integration Approach:** `OnboardingView` 레이아웃 및 공통 Shell 수정, 상단 인셋 바 추가, 색상 토큰 적용.
- **Existing Pattern Reference:** `docs/frontend/onboarding-window-modern-package.md` (레이아웃/색상/모션 규칙)
- **Key Constraints:** 기능 로직 변경 금지(TCA state/Reducer 변경 없음), UI 레이아웃과 스타일만 수정.
