# Story 1.7: Onboarding Window Modern UI Refresh - Brownfield Addition

## Status
Ready for Review

## Story

**As a** 신규 사용자,
**I want** 온보딩 윈도우가 Raycast 스타일의 미니멀한 레이아웃과 현대적 비주얼로 정리되며 상단 인셋 바 내비게이션을 제공하고,
**so that** 초기 경험에서 신뢰감과 집중도를 높이고 다음 단계로 자연스럽게 이동할 수 있다.

## Acceptance Criteria

1. 상단 히어로 타이틀 영역(컨텐츠 내 헤더 블록)을 제거하고, 좌/우 섹션 또는 중앙 정렬 기반 레이아웃으로 구성한다. (시스템 윈도우 타이틀 바는 유지)
2. 시스템 윈도우 타이틀 바는 투명 처리하고 타이틀 텍스트는 보이지 않게 한다(제목 표시 없음).
3. 상단 인셋 바를 추가한다: 좌측 `Back`, 중앙 도트 페이지네이션(스텝 수와 동일, 현재 4개), 우측 `Next` 버튼(Primary).
4. 상단 `Next`는 기존 `Next`와 동일 동작/게이팅이며, `Next`가 비활성일 때 동일하게 비활성화된다. `Enter` 키는 `Next` 실행 단축키로 동작한다.
5. 기존 온보딩 스텝/상태머신/게이팅 로직은 변경하지 않는다.
6. 하단 `Back`/`Next` 내비게이션은 제거하고, 상단 인셋 바가 주요 내비게이션 역할을 수행한다.
7. `OnboardingWindow`는 `visibleFrame` 기준 50% 크기를 기본으로 한다(최소 720x480, 최대 1100x720 범위 내에서 clamp).
8. 윈도우 트래픽 버튼 중 최소화/최대화는 비활성화하고, 항상 위(always on top)로 유지한다.
9. 모션은 윈도우 fade-in만 적용한다(200~240ms, ease-out).
10. Accent 컬러 `#FC9A30` 적용이 Primary CTA/활성 스텝/진행률에 일관되게 반영된다.
11. 다크/라이트 모드 모두에서 대비/가독성 문제가 없다.

### Layout Spec (KR)

**디자인 방향**
- Raycast 스타일의 미니멀함을 유지하되, 과도한 플랫 느낌을 피하고 은은한 레이어/깊이로 현대적 감도를 확보한다.
- 크롬(테두리/구분선)은 최소화하고, 정보 계층은 타이포/간격/명도 대비로 구분한다.
- 상단 인셋 바는 컨텐츠 집중을 돕는 “컨트롤 스트립” 역할로만 사용한다.

**그리드/스페이싱**
- 8pt 그리드 기반. 주요 수평 패딩 24px, 섹션 간 기본 간격 16px, 카드 내부 패딩 12~16px.
- 컨텐츠 컨테이너 최대 폭 1040px, 최소 폭 880px.
- 2열 레이아웃은 윈도우 폭 ≥ 1200px에서 5:7 비율 적용, 그 미만은 단일 컬럼으로 스택.

**상단 인셋 바**
- 높이 44~48px, 배경은 `ultraThinMaterial`에 가까운 톤(라이트: 90~95% 밝기, 다크: 12~18%).
- 좌측: `Back` 텍스트 버튼(아이콘 없이 텍스트 중심, hover 시 과한 강조 금지).
- 중앙: 도트 페이지네이션(스텝 수 동적, 현재 4개).
- 우측: `Next` Primary 버튼(Accent `#FC9A30`).

**도트 페이지네이션**
- 크기 6~8px, 간격 8~10px.
- 활성 도트는 `#FC9A30` 필, 비활성은 30~40% 불투명도.
- 완료된 스텝은 중간 톤(60% 불투명도)로 표시 가능(선택).

**버튼 스타일**
- `Next`: 10~12px 라운드, 텍스트 13~14px, 높이 28~32px.
- `Back`: 텍스트 버튼, 비활성 시 40~50% 불투명도.
- 키보드 포커스 링은 시스템 기본을 유지(접근성 일관성).

**본문 컨텐츠**
- 좌측 영역(또는 상단 영역): 스텝 타이틀(28~32px), 서브카피(13~15px), 신뢰 카드(개인정보 안내/재설정 안내).
- 브랜딩은 상단 인셋 바가 아니라, 본문 좌측 상단의 작은 로고/워드마크(20~24px)로 배치(선택).
- 우측 영역(또는 하단 영역): 기존 `OnboardingStepViews`의 실질 입력 UI 렌더.
- 카드/섹션은 12~16px 라운드, 12~16px 패딩, 8~12px 갭 유지.
- 타이포그래피는 macOS 기본 시스템 폰트(SF Pro) 사용을 유지한다.

**모션/톤**
- 윈도우 등장 시 fade-in(200~240ms, ease-out)만 적용.
- 강조색 `#FC9A30`은 Primary CTA, 현재 스텝 도트, 진행 강조 요소에만 사용.
- 라이트/다크 모두에서 텍스트 대비 4.5:1 이상을 확보한다.
- 배경은 아주 약한 그라디언트(상단 밝고 하단 살짝 어두움) 또는 미세 노이즈를 사용해 깊이감을 준다(과한 패턴 금지).

**윈도우 크롬**
- 타이틀 바는 투명 처리하고 타이틀 텍스트는 숨김.
- 컨텐츠가 타이틀 바까지 확장되어 자연스럽게 이어지도록 처리.
- 트래픽 버튼은 닫기만 활성화하고 최소화/최대화는 비활성화.
- 윈도우는 항상 위(always on top)로 유지한다.

### Prompt (EN)

Design a macOS onboarding window in a modern, Raycast-inspired minimal style. Remove the in-content hero header. Make the system title bar transparent and hide the window title text; extend content into the title bar. Disable minimize/zoom traffic light buttons (keep close enabled) and keep the window always on top. Build a top inset control strip: Back on the left, step dots centered (dynamic count, currently 4), and a primary “Next” button on the right. Do not place a brand slot in the top bar; if branding is needed, place a small logo/wordmark inside the left content column (20–24px height). Keep all existing content views and logic intact; only update shell/layout and styling. Use a 3-zone vertical structure: top inset bar, content area, bottom navigation (bottom nav removed; top bar is primary). Apply an 8pt grid, 24px horizontal padding, and a centered container (max width ~1040px, min width ~880px). Use a 2-column layout (5:7) when window width ≥ 1200px; otherwise stack into a single column. Use subtle material-like backgrounds, minimal dividers, soft elevation, and a faint vertical gradient or micro-noise for depth. Accent color #FC9A30 is reserved for the primary CTA and active step dot only. Typography should follow macOS SF Pro defaults with clear hierarchy (title 28–32px, body 13–15px). Support both light and dark mode with strong contrast (≥4.5:1). Motion: only a window fade-in transition (200–240ms, ease-out). Do not change any TCA reducers or state logic. “Enter” is the keyboard shortcut for Next.
