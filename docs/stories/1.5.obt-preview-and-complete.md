# Story 1.5: Indexing Preset (OBT) Preview + Complete → File Manager Open

## Status

Draft

## Story

**As a** 신규 사용자,  
**I want** `Indexing Preset(OBT)`을 읽기 전용으로 확인하고 온보딩 완료 시 파일 관리자 창 1개가 자동으로 열리게,  
**so that** 설정 완료 직후 즉시 제품 가치를 경험할 수 있다.

## Acceptance Criteria

1. `Indexing Preset(OBT)` 스텝은 읽기 전용 프리뷰를 표시한다(편집 UI 없음, “Open OBT” 버튼 없음).  
2. `Indexing Preset(OBT)` 스텝은 “인덱싱 범위(프리셋) 설정”을 위한 UI 자리이며, 실제 편집/적용 기능은 OBT에서 제공한다.  
3. `Complete`에서 완료 플래그 저장 후 파일 관리자 창 1개를 자동 오픈한다.  
4. 완료 후 자동 오픈되는 파일 관리자 창의 초기 경로는 `SettingsFeature.getDefaultTabPath()`를 따른다.  
5. 완료 후 전환 실패 시 `Retry`를 제공하고, 실패 사유를 요약 표시한다.  
6. 완료 플래그가 저장된 이후 앱을 재실행하면 온보딩 없이 파일 관리자 창이 열린다.  

## Tasks / Subtasks

- [ ] Implement `IndexingPresetFeature` (TCA) read-only preview UI (AC: 1, 2)
  - [ ] Implement/extend `IndexingPresetFeature` as a TCA child reducer scoped from `OnboardingFeature`
  - [ ] Render included/excluded paths in read-only form
  - [ ] Ensure there is no edit affordance and no “Open OBT” button
- [ ] Implement `CompleteFeature` (TCA) + completion flag + transition (AC: 3–6)
  - [ ] Implement/extend `CompleteFeature` as a TCA child reducer scoped from `OnboardingFeature`
  - [ ] Persist “onboarding completed” flag via a dedicated TCA dependency (UserDefaults-backed)
  - [ ] On completion, open exactly 1 file manager window via an injected dependency (do not hide side effects in views)
  - [ ] Ensure initial path uses `SettingsFeature.getDefaultTabPath()`
  - [ ] Handle failure to open window: show `Retry` and message
- [ ] Integrate with Onboarding root routing (AC: 6)
  - [ ] Root routing uses completion flag to skip onboarding on subsequent launches
- [ ] Tests (AC: 3–6)
  - [ ] Unit tests using TCA `TestStore` for completion flag persistence and subsequent routing behavior

## Dev Notes

- Depends on:
  - Story 1.2 (step state machine)
  - Story 1.1 (file manager window creation path exists and is used)
- UX/AC source:
  - `docs/frontend/onboarding-window-spec.md#indexing-preset-obt--read-only-preview`
  - `docs/frontend/onboarding-window-spec.md#acceptance-criteria-locked-for-voy-111`
- TCA architecture notes:
  - Implement this as two child reducers: `IndexingPresetFeature` (read-only preview) and `CompleteFeature` (completion + transition).
  - Cross-step routing and “skip onboarding if completed” logic remains in the root `OnboardingFeature`.
- Integration point:
  - File manager window is created via `AppDelegate.createNewWindow(path:asTab:)` which instantiates `FileManagerWindowController`. [Source: `docs/architecture/source-tree.md`]
- Notes:
  - 초기 인덱싱(`POST /index`, 대상 `/`)은 CBT 범위로 계획되어 있으며, VOY-111에서는 `Permissions` 스텝에서 안내(placeholder)만 제공한다(Story 1.4).
  - 이 스텝은 “인덱싱 범위(프리셋) 편집”을 위한 자리이며, 실제 편집/적용은 OBT에서 제공한다.
