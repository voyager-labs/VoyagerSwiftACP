# Story 1.5: Permissions Step Indexing Preset (OBT) Preview + Complete → File Manager Open

## Status
Done

## Story

**As a** 신규 사용자,  
**I want** `Permissions` 단계에서 `Indexing Preset(OBT)` 프리뷰를 읽기 전용으로 확인하고 온보딩 완료 시 파일 관리자 창 1개가 자동으로 열리게,  
**so that** 권한 획득 직후 다음 단계 정보를 확인하고 설정 완료 직후 즉시 제품 가치를 경험할 수 있다.

## Acceptance Criteria

1. `Permissions` 스텝에서 FDA가 `Granted`일 때 `Indexing Preset(OBT)` 읽기 전용 프리뷰가 표시된다.  
2. 프리뷰는 편집 UI가 없고, “Open OBT” 버튼이 없다.  
3. 프리뷰는 실제 편집/적용이 OBT에서 제공됨을 명시하고, `Next` 게이팅에는 영향을 주지 않는다.  
4. `Complete`에서 완료 플래그 저장 후 파일 관리자 창 1개를 자동 오픈한다.  
5. 완료 후 자동 오픈되는 파일 관리자 창의 초기 경로는 `SettingsFeature.getDefaultTabPath()`를 따른다.  
6. 완료 후 전환 실패 시 `Retry`를 제공하고, 실패 사유를 요약 표시한다.  
7. 완료 플래그가 저장된 이후 앱을 재실행하면 온보딩 없이 파일 관리자 창이 열린다.

- Key files (expected touch points):

- Integration point:
  - File manager window is created via `AppDelegate.createNewWindow(path:asTab:)` which instantiates `FileManagerWindowController`. [Source: `docs/architecture/source-tree.md`]
- Notes:
  - 용어: CBT는 VOY-111 범위(프리뷰 + 초기 인덱싱 트리거 포함), OBT는 후속 단계(프리셋 편집/적용 제공).
  - 프리뷰 데이터는 CBT 범위에서는 고정 예시 리스트(placeholder)로 표시한다.
  - 초기 인덱싱은 `Permissions` 스텝에서 `/`부터 실행되며 백그라운드에서 계속 동작한다(Story 1.4).
    - TODO(VOY-117, VOY-88): 인덱싱 포트 연동 및 인덱싱 엔드포인트 완료 후 실제 트리거 연결.
  - Files & Folders 권한 요청은 `Open Panel` 없이 Desktop/Documents/Downloads에 직접 접근을 시도해 OS 권한 팝업(TCC)을 유도한다.
    - 권한 팝업은 폴더별로 순차 노출될 수 있다.
  - Full Disk Access는 시스템 설정에서 사용자가 직접 앱을 추가/토글해야 하며, 일반 앱이 자동 추가/승인하는 API는 없다.
    - MDM(조직) 환경에서는 PPPC 프로파일로 사전 허용 가능하다. (공식 문서 기준)
  - 프리셋 편집/적용은 OBT에서 제공하고, CBT에서는 읽기 전용 프리뷰만 표시한다.
  - 온보딩 플로우에서는 `Indexing Preset` 전용 스텝을 두지 않는다.
  - 공식 문서 기준으로 `Full Disk Access`는 PPPC의 `System Policy All Files` 항목이며 사용자 승인 필요로 정의된다. MDM 프로파일로 사전 허용 가능하지만, 일반 앱에서 자동 추가/승인은 불가하다.
    - 참고: https://support.apple.com/guide/deployment/privacy-preferences-policy-control-payload-dep38df53c2a/web
    - 참고: https://developer.apple.com/documentation/devicemanagement/privacypreferencespolicycontrol
