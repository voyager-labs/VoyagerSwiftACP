## Context

1. ### AI 챗봇과 파일 간의 빈번한 맥락 전환

- 핵심 상황  
  - 특정 논문의 핵심 내용을 요약하거나 코드를 디버깅하기 위해 파일을 AI 챗봇(웹)이나 IDE에 드래그 앤 드롭하는 과정을 하루에도 수십 번 반복함  
- 현재 방식  
  - Finder에서 폴더 깊숙이 있는 PDF, 코드 파일을 일일이 찾아서 복사하거나 웹 브라우저의 챗봇 창으로 끌어다 놓음  
  - 질문 내용이 바뀌거나 새 파일이 필요해질 때마다 도구(IDE ↔ 브라우저 ↔ Finder) 간 화면 전환이 발생함

2. ### 여러 파일의 조합에 대한 분석 니즈

- 핵심 상황  
  - 단일 파일이 아니라, 여러 논문이나 수십 개의 코드 파일을 한 번에 컨텍스트로 묶어 AI에게 질의해야 하는 상황이 잦음  
- 현재 방식  
  - 폴더에서 필요한 파일들을 임시 폴더로 복사해 모으거나, 여러 창을 띄워놓고 순차적으로 프롬프트와 함께 입력함

## Pains

- Finder에서 파일을 찾고, AI 도구로 전환하여 파일을 로드한 뒤 프롬프트를 작성하는 일련의 과정이 매번 번거로움  
- 이로 인해 작업 흐름이 끊기고 심리적인 마찰(Friction)이 발생해 생산성이 저하됨

- AI에게 전달하기 위해 특정 부분만 잘라낸 코드 파일이나 텍스트를 임시로 계속 만들게 됨  
- 작업이 끝난 후 이 임시 파일들을 정리하지 않아 Desktop이나 Downloads 폴더가 어질러짐
