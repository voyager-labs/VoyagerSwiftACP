# Non-Goals

- 노트·지식관리·뷰어·에디터를 대체하지 않음. 파일의 실행 주체는 해당 분야의 특화된 앱이고, 우리는 파일 브라우징·매니징에 집중
- 클라우드 스토리지 서비스를 대체하거나, 동기화 엔진·가상 드라이브를 직접 구축하는 것을 목표로 하지 않음
- 기존 파일 시스템 자체를 대체하거나 별도의 저장 구조를 강제하지 않음
- Notion·Slack 류의 풀스택 팀 협업 워크스페이스를 만드는 것을 목표로 하지 않음. 여기서 "워크스페이스"는 파일 작업을 위한 통합 작업 공간을 의미하며, 초기 범위는 개인·소규모 팀 리더의 파일·의사결정 레이어에 한정
- 범용 AI 챗봇·웹 검색 엔진 대체 지향 아님. 파일 맥락에 특화된 대화 경험에 집중
- 시스템 전역 자동화 서비스/플랫폼을 대체하지 않음
- macOS 전용으로 시작하며, Windows/Web/모바일은 이후 검토
- 데이터 수집·광고 기반 수익 모델을 고려하지 않음
- 기본 파일 관리·정리 기능을 위해 계정 로그인을 필수로 요구하지 않음
