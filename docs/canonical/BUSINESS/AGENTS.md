# BUSINESS AGENTS

## Scope

`BUSINESS/`는 Voyager의 회사/사업계획 정본을 관리합니다.

## Rules

- 피치덱, 사업계획서, 투자 제안서, 회사 소개, 지원사업 신청서를 작성하거나 수정하기 전에는 작업 목적에 맞는 주제별 정본 파일을 직접 읽습니다.
- PDF나 과거 신청서에서 발견한 문장은 바로 정본으로 취급하지 않습니다. 재사용할 claim만 해당 주제별 정본 파일에 정리합니다.
- 출처 간 수치가 다르면 덮어쓰지 말고 `검토 필요`로 남깁니다.
- 개인정보, 서명, 동의서, 연락처, 제출 서약 문구는 원본 파일에 남기고 이 디렉터리에는 필요한 범위만 메타데이터로 기록합니다.
- 지원사업 문체와 투자자 피치 문체를 섞지 않습니다.
- 대표자 생년월일, 휴대폰 번호, 개인 주소, 서명, 개인정보 동의서 문구는 정본 claim으로 재사용하지 않습니다.
- 지원사업 신청서용 서약 문장과 특정 지원사업의 선정/탈락 맥락은 투자자용 팀 역량 claim처럼 직접 재사용하지 않습니다.

## External Research and Citations

- 외부 리서치 claim은 발행기관, 문서명 또는 페이지명, URL, 발행일 또는 기준일, 접근일을 함께 남깁니다.
- 공개 웹 자료는 원본 파일을 레포에 복사하지 않고 URL과 접근일을 남깁니다.
- 유료 리포트, 비공개 PDF, 계약상 재배포가 애매한 원문은 Drive 원본 위치만 기록하고 레포에는 인용 가능한 claim과 출처 메타데이터만 남깁니다.
- 출처가 확인되지 않은 외부 벤치마크, 경쟁사 수치, 시장 규모, 성장률은 확정 claim으로 쓰지 말고 해당 주제 파일에 `출처 확인 필요`로 남깁니다.
- `Time Loss Breakdown`처럼 시간 손실, 비용 손실, 생산성 손실을 항목별로 쪼갠 표는 각 항목의 원출처 또는 내부 산식 출처를 함께 남깁니다.
- 정량 표에는 가능한 한 `Source`, `Basis`, `Source status` 중 하나를 두고, 출처가 없으면 `출처 확인 필요`를 명시합니다.
- 산출물에 수치나 외부 비교를 넣을 때는 기준일 또는 source를 함께 표기합니다.

## Output Rules

- 피치덱, 사업계획서, 투자 제안서, 회사 소개, 지원사업 신청서는 정본이 아니라 주제별 정본 파일에서 파생되는 외부 산출물입니다.
- 외부 산출물을 만들 때는 출처 PDF의 문장을 그대로 가져오지 말고, 산출물 목적에 맞게 압축하고 재배열합니다.
- 제품 원라이너는 기본적으로 명사구형 문구 `쌓이는 파일과 노트를 재사용 가능한 지식 자산으로 바꾸는 AI 파일 워크스페이스, 보이저(Voyager)`를 사용합니다.
- 원라이너를 문장으로 풀어야 하는 경우에도 `Voyager는...` 형태를 기본값으로 쓰지 않습니다.
- 가격 정책은 `Core License + Basic/Go + Automation`을 최신 기본값으로 봅니다. 과거 `Free` 또는 `Freemium SaaS` 문구는 검토 없이 재사용하지 않습니다.
- Core License 가격은 기본적으로 `$5 + tax`처럼 tax-exclusive로 표현합니다.
- trial은 지속 Free plan이 아니라 기간 제한 Full Suite Trial로만 표현합니다.
- 투자자용 산출물에는 지원사업식 장문 설명, 개인정보/서약/동의서 맥락, 기준일 없는 traction 숫자, 검토되지 않은 장기 KPI를 확정 표현처럼 넣지 않습니다.
