# 13. Roles & Responsibilities

## User (사람)
- 외부 서비스 계정 생성/결제, API Key 발급/회수/교체 책임 보유
- 로컬 개발용 `.env` 작성/제공(커밋 금지), CI는 `Secrets`에 보관 후 워크플로에서 주입
- 인덱싱 루트 결정(정책: full path 기준), 민감 경로/파일 유형 제외 규칙 제공
- 민감 데이터/로그 스크러빙 정책에 동의 및 변경 시 고지
- 시스템 단축키와의 충돌을 고려해 Dock 단축키 최종 확정에 참여

## Developer Agent (개발)
- 코드/구성/마이그레이션/자동화(인덱싱 등) 구현과 유지보수 주도
- 테스트/검증(백엔드 pytest 스모크, macOS 기본 UI 흐름) 설계/운영, 품질 게이트 협업
- 보안 가드레일 준수: 비밀키 코드/로그 비노출, `.env`/CI Secrets 사용, 로그 스크러빙 반영
- Brownfield 호환 원칙 준수: additive 변경, feature flag 가드, 우아한 폴백
- 문서 동기화: PRD/아키텍처/UX 가이드 변경 시 최소한의 추적 가능성 유지
