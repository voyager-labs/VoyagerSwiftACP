# 4. 사용자 및 사용 시나리오(요약)

- 사용자: macOS 사용자(혼합 숙련도, 자연어 기반 탐색/정리를 원하는 파워유저 포함)
- 핵심 플로우(1차):
  1) 단축키로 Command Dock 호출 → 질의 입력
  2) 백엔드 메타데이터 검색 수행 → 결과 반환
  3) 결과를 리스트/컬렉션 뷰로 표시
- 핵심 플로우(2차):
  1) “X 조건으로 컬렉션 만들어줘” 요청
  2) 조건 파싱 → 컬렉션 생성 → 사이드바 고정/관리(이름 변경/삭제)

## 타깃 사용자 (요약)

- 인디/소규모 테크 파운더
- macOS 중심, 문서형 워크플로, 키보드 단축키 선호
- 로컬+클라우드 병행, 프라이버시 민감
- 제외: Windows/Web 우선, 팀 협업 워크스페이스 필수, 특수 미디어 통합 요구
