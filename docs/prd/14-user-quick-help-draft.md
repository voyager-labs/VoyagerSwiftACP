# 14. User Quick Help (Draft)

- Dock 열기: (예) `⌘K` 또는 `⌘⇧K` — 최종 단축키는 앱 내 설정/도움말에 표기
- 질의 입력: 파일 유형/기간/경로 키워드로 자연어 질의(예: "pdf in Documents modified last month")
- 결과 탐색: ↑/↓ 이동, Enter 열기, ESC Dock 닫기(포커스 복귀)
- 빈 결과: "No results…" 메시지를 확인하고 질의를 조정
- 오류: 연결 실패 시 “Can’t reach the service…” 메시지 확인 후 재시도
- 컬렉션(2차): “~한 컬렉션 만들어줘” 형태로 생성, 사이드바에서 이름 변경/삭제
