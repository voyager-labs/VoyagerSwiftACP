# 5. 요구사항

## 5.1 기능 요구사항(Functional)

1) Command Dock

   - 글로벌 또는 앱 포커스 내 단축키로 호출(예: ⌘K 또는 ⌘⇧K; 최종 단축키는 충돌 검토 후 확정)
   - 입력 히스토리/자동완성(후속), 실행 시 비동기 진행 표시, ESC로 닫힘
   - 파일 탐색 영역과 자연스러운 포커스 전환(키보드만으로 왕복 가능)
2) 메타데이터 기반 검색(MVP)

   - 인덱싱 대상: 사용자 홈 이하 선택 경로(초기엔 수동 지정)
   - 파이프라인: 파일 메타 추출(core/file_crawler) → (선택) 청크 → 메타데이터 색인 저장(SQLModel)
   - 자연어 → 메타데이터 필터 변환(예: 확장자/변경일/경로/UTI/크기 등)
   - 검색 API: `POST /search` (자연어 또는 구조화된 필터) → 결과(파일 경로, 주요 메타, 점수/정렬 키)
3) 컬렉션 생성/관리

   - 자연어 질의/조건을 파싱하여 컬렉션 정의 생성
   - 컬렉션 보관: SQLite(백엔드) 영속화, 사이드바에 노출, 이름 변경/삭제
   - 컬렉션 열람 시 동적 재질의 또는 스냅샷 방식은 옵션화(초기엔 재질의 권장)
4) macOS-백엔드 연동

   - 앱 실행 시 백엔드 자동 기동(현 `BackendManager*` 방식을 유지) 및 로그 파일 옵션
   - `.env` 또는 plist 기반 설정으로 포트/명령어/로그 경로 주입

## 5.2 비기능 요구사항(Non-Functional)

- 성능: Dock 입력 → 최초 결과 노출까지 p50 < 800ms(작은 코퍼스 기준), 인덱싱은 백그라운드 처리
- 안정성: 앱/백엔드 프로세스 상태 감시, 자동 재시작 옵션(후속)
- 보안/개인정보: 로컬 우선 처리, 민감 데이터는 외부 전송 금지(명시적 옵트인 제외). 외부 키/자격증명은 Keychain/CI 마스킹 등 안전 저장. 민감 경로 인덱싱 제외 옵션 제공
- 관측성: 백엔드 로그 레벨 조정, macOS 측 사용자 행동 로그(익명/옵트인) 설계(후속)

## 5.3 제품 원칙 (Product Pillars)

- Unified Flow: 하나의 입력 표면에서 탐색→관리→사용 흐름 유지
- Logical Collections: 조건/의미/수동 큐레이션으로 묶는 작업 집합 유지, 경로 변경에도 참조 안정성 유지
- Reusable Actions: 기준을 선언적으로 저장·재실행(본 PRD 범위는 2차 이후에 단계적 반영)
- Controllable Execution: 변경 제안/승인/거절, 드라이런/되돌리기 제공으로 신뢰성 확보
