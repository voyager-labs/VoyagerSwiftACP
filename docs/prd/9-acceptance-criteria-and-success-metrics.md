# 9. 수용 기준 및 성공 지표

- 기능 수용 기준(기초 문서 단계):
  - Dock UI 통합: 토글/포커스/ESC 동작 및 기본 접근성 라벨링
  - 검색 API(`/search`) 구현 및 결과 표시(리스트/그리드, 정렬 기본)
  - 인덱싱 API(`/index`) 구현 및 요약 반환(초기 동기)
  - UI 상태 전이(Loading/Empty/Error) 구현 및 사용자 메시지 표준화
- 성공 지표(초기):
  - Dock 응답 p50 < 800ms, p95 < 1500ms(제안)
  - Dock 호출 성공률 > 99%(제안)
  - 첫 질의 성공률(MVP) > 70%, 후속 > 85%(제안)
- 재탐색/재검색 비율 베이스라인 대비 30% 감소(제안)

## MVP Exit Criteria (Gate)
- 상기 기능 수용 기준 충족 및 회귀 스모크 통과
- 5.2 접근성 베이스라인 및 5.4 상태(Loading/Empty/Error) 구현 확인
- 로컬 회귀 스모크 체크리스트 통과(12장)
- 성능 초기 지표(응답 p50/p95) 관찰치 보고 및 허용 범위 내
