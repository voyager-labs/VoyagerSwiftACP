# ONB Engineering Docs

## Canonical product category

- Category: `ONB`
- Title: Onboard
- Canonical inventory: `../../canonical/PRODUCT/04_FEATURE_INVENTORY/FEATURE_CATEGORIES/data.tsv`
- Description: 첫 실행 시 기본 개념, 권한 설정, 초기 구성을 빠르게 마칠 수 있도록 돕는 온보딩 기능 묶음

## Active engineering docs

이 category에 속한 구현 결정, 런타임 흐름, 코드/테스트 topology를 durable documentation으로 남길 때 이 위치를 사용한다.

필요할 때 사용하는 하위 디렉터리:

- `concerns/`
- `flows/`
- `decisions/`
- `implementation/`

## Traceability rule

이 category의 문서는 canonical `feature_id`, `interaction_id`, contracts, flows, feature specs, IA regions를 링크하고 제품 acceptance criteria를 복제하지 않는다.
